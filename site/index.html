🪛 QuickDock 插件中心

为 QuickDock 开发的非内置插件，提供 Windows 安装包（主程序目前仅支持 Windows）。

接口压测 v0.1.1
io.github.parieses.api-loadtest

功能丰富的 HTTP 接口压测工具：支持并发/时长双模式、自定义 Header 与 Body、实时 QPS 与延迟分布(p50/p90/p95/p99)、状态码分布、错误率统计与结果一键导出

⬇ Windows
颜色工具 v0.3.0
io.github.parieses.color-converter

颜色格式互转（HEX / RGB / HSL）+ 屏幕取色，支持常见英文色名识别

⬇ Windows
对比工具 v0.2.1
io.github.parieses.compare

文件/图片对比（元数据 + 图片预览 + 文本内容差异）与文本块逐行 Diff 合二为一

⬇ Windows
Crontab 解释器 v0.2.1
io.github.parieses.cron-explainer

解析 cron 表达式，显示人类可读描述、下次执行时间和可视化时间表

⬇ Windows
磁盘分析器 v0.1.1
io.github.parieses.disk-analyzer

可视化磁盘空间占用分析工具，类似 SpaceSniffer，支持树图展示目录结构

⬇ Windows
HTTP 状态码速查 v0.2.1
io.github.parieses.http-status

查询 HTTP 状态码含义、描述和常见场景

⬇ Windows
PDF 工具箱 v0.1.2
io.github.parieses.pdf-toolkit

PDF 处理工具箱：合并/拆分/压缩/加水印/提取图片/PDF 转图片，无需安装 Adobe Acrobat

⬇ Windows

安装方法：打开 QuickDock → 插件管理 → 从文件安装 → 选择下载的 zip（或直接把 zip 拖进插件管理页）。升级时覆盖安装，自动备份旧版本。
下载 404？对应平台还没有 Release 资产，或该插件没发布对应平台的安装包，见 Releases。更多信息：仓库主页。
