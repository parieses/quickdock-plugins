# 敏感信息扫描

扫描项目目录，找出意外硬编码的密钥、私钥、令牌与身份证号等敏感信息，防止它们被提交进仓库或在代码里长期留存。

> 只扫描你**明确选择**的目录，所有匹配都在本机完成、不会上传。命中结果默认脱敏显示。

## 能扫出什么

| 类别 | 规则 | 说明 |
|---|---|---|
| 密钥/凭证 | AWS Access Key、AWS Secret、Google API Key、Stripe 密钥、`.env` 敏感变量、通用 `api_key/secret/token=` 赋值 | 高 |
| 令牌 | Slack Token / Webhook、GitHub Token、JWT | 高 / 中 |
| 私钥 | PEM 格式私钥块（RSA/EC/OPENSSH/PGP） | 高 |
| 个人身份 | 身份证号（含校验位）、银行卡号（Luhn 校验）、手机号、邮箱 | 中 / 低 |

身份证与银行卡带**校验位验证**，银行卡要求通过 Luhn 算法，以此压低误报。手机号、邮箱误报较高，默认**关闭**，可按需在规则面板开启。

## 用法

1. 点「选择目录」挑一个项目根目录（会递归扫描子目录）。
2. 在规则面板勾选要启用的检测器（默认全部启用，PII 中的手机号/邮箱除外）。
3. 可选：勾选「含 Git 历史」，会额外跑 `git log -p --all` 扫描**已经提交过**的密钥。
4. 点「开始扫描」。结果按严重度排序，命中值默认脱敏，勾「显示明文」可见原值，可一键导出为文本。

## 设计取舍

- **自动跳过**：二进制文件（按扩展名 + NUL 字节探测）、`node_modules` / `.git` / `vendor` / `dist` 等目录、单文件超过上限（默认 2 MB，可调）。
- **去重**：同一文件、同一行、同一个值的密钥只记一次，避免一条 AWS Key 被多条规则重复命中。
- **不扫系统/他人目录**：本插件只处理你主动选的目录，不做全盘或系统目录扫描。

## 发现密钥之后

扫描只是第一步。命中后请：

1. **立即在对应平台吊销并轮换**密钥（GitHub / AWS / Stripe 等都支持一键吊销），光删代码不够——历史提交里可能还有。
2. 若已提交进 Git，用 `git filter-repo` 或 BFG 清理历史，或干脆换新密钥。
3. 把密钥迁到环境变量 / 密钥管理服务，别再写进源码。

## 命令（供宿主调用）

| 命令 | 作用 |
|---|---|
| `scan` | 启动一次扫描，返回 `sessionId` |
| `scan-poll` | 轮询进度与命中结果 |
| `scan-cancel` | 取消正在进行的扫描 |
| `rules` | 返回全部规则元数据（前端用于渲染规则开关） |

## 权限

- `filesystem`：读取你选择的目录进行扫描。
- `process: ["git"]`：仅在勾选「含 Git 历史」时使用，调用 `git` 读取提交历史。

## 构建

```bash
go build -o secrets-scanner.exe .
```
